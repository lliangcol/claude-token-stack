# Synthetic Demo Case Study

Evidence type: synthetic/demo wiring proof.

This case study describes the built-in synthetic benchmark path used for `v0.1.0-rc` preparation. It is not a real repository savings proof.

## baseline

The synthetic baseline is generated by:

```bash
node bin/cts.js benchmark baseline synthetic-only --target .
```

Representative baseline tasks:

- `code-discovery`
- `test-failure`
- `long-log`

Expected baseline evidence files:

- `.token-stack/reports/baseline/code-discovery.json`
- `.token-stack/reports/baseline/test-failure.json`
- `.token-stack/reports/baseline/long-log.json`

## post

The synthetic post phase is generated by:

```bash
node bin/cts.js benchmark post synthetic-only --target .
node bin/cts.js collect-metrics --target .
node bin/cts.js compare-metrics --target .
```

Expected post evidence files:

- `.token-stack/reports/post/code-discovery.json`
- `.token-stack/reports/post/test-failure.json`
- `.token-stack/reports/post/long-log.json`
- `.token-stack/reports/metrics-collected.json`
- `.token-stack/reports/metrics-summary.json`
- `.token-stack/reports/metrics-summary.md`

## warnings

Expected warnings in the demo context:

- Optional tools may be reported as `WARN` when absent.
- Synthetic data may recommend against entering block mode.
- Bash-backed commands require Git Bash, WSL2, macOS, or Linux.
- Native PowerShell should be used for scaffold and direct hook smoke tests unless Bash is available.

## false positives

False-positive review should inspect:

- `.claude/logs/token-guard.log`
- `.claude/logs/cbm-gate.log`
- `.token-stack/reports/verify-report.json`

Known demo limitation: synthetic events are intentionally broad and noisy. A warning in this demo does not prove that the same rule should block real developer work.

## rollback notes

Fast disable:

```bash
export TOKEN_GUARD_MODE=off
export CBM_GATE_MODE=off
```

PowerShell:

```powershell
$env:TOKEN_GUARD_MODE = "off"
$env:CBM_GATE_MODE = "off"
```

For full removal, use:

- `docs/rollback.md`
- generated `docs/claude-token-stack-rollback.md` in the target repository
- `.bak.<timestamp>` files created by scaffold before overwriting existing files

## limitation statement

Synthetic/demo evidence does not equal real repository savings proof. It shows that scaffold, hooks, verification, benchmark, metrics collection, comparison, and rollback documentation are connected. Real savings claims require representative baseline/post tasks, retained evidence files, and a clear label for the evidence type.
